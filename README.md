# Hackpad

A custom 9-key macropad designed from scratch with a custom PCB, OLED display, and programmable keys.

> **Project Status: Design Phase**
>
> The physical Hackpad has not been assembled yet. The required components will be provided by Hack Club, after which the physical prototype will be built and tested.

## Features

* 9 programmable mechanical keys
* 0.91" OLED display
* Custom PCB designed in KiCad
* Custom hardware layout
* Programmable using KMK / CircuitPython
* Custom OLED graphics
* Designed to be assembled into a physical prototype

## OLED Display

The Hackpad includes a small OLED display that will be used to display custom graphics.

The current design includes a small penguin with snowflakes surrounding it.

## Hardware

The project is designed around a Seeed Studio XIAO microcontroller.

Other hardware includes:

* 9× mechanical keyboard switches
* 9× keycaps
* 0.91" OLED display
* Custom PCB
* Custom case
* Supporting electronic components

## Software

The Hackpad will use:

* CircuitPython
* KMK Firmware
* Adafruit CircuitPython libraries

The firmware will control the keyboard keys and OLED display.

## Design

The project is currently being developed digitally before physical assembly.

### PCB

The PCB is designed using **KiCad**.

### Case

The case will be designed to hold the PCB, switches, OLED display, and microcontroller.

### OLED

The OLED will display custom pixel-art graphics when the Hackpad is powered on.

## Goal

The goal of this project is to design and build a fully functional custom macropad from the ground up, combining custom hardware, PCB design, firmware, and a custom physical enclosure.

The final result will be a working physical Hackpad with programmable keys and an OLED display.

## Project Status

**Current stage:** Digital design / prototyping

**Physical prototype:** Not yet assembled

**Next major step:** Receive the components and begin physical assembly.
